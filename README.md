# About this project

This is a weather app built with HTML, CSS and JavaScript. 
It fetches live weather data from the Open-Meteo API based 
on the city the user searches for. The app displays the 
current temperature, humidity, wind speed, UV index and a 
5-day forecast. I built it by first setting up the HTML 
structure and CSS styling, then writing JavaScript functions 
to fetch data from the API and update the page 
with real weather information.
